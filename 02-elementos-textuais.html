Aprendendo sobre elementos textuais do HTML

O que são os elementos textuais?

os elementos servem para destacar, enfatizar ou dar um significado a partes especificas do conteudo.

Elemento strong

É muito Importante aprender a estutura do HTML.

A tag strong serve para indicar que determinado texto possuie forte importancia

Elemento b

Aprenda HTML, CSS, e Javascript para criar paginas web.

A tag b tambem costuma deixar o texto em negrito

Elemento em

Voce realmente precisa estudar.

O elemento em comunica que aquele trecho deve receber uma determinada enfase dentro da frase.

Elemento i

Termo software é utilizado com frequencia na área de tecnologia.

O elemento i possui a mesma formatação visual que o elemento em, porem, não possui valor semantico. é apenas estilo visual.
