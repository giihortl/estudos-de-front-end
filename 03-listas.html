o que sao listas HTML?

Uma lista é uma sequencia de itens relacionados entre si.
No html, existe principalmente, 3 tipos de listas
Listas nao ordenadas, Listas ordenadas e Listas de descrição

Lista nao ordenada (ul)

uma lista nao ordenada é usada quando a ordem dos elementos/itens nao importa

  • Banana
  • Maca
  • Arroz
  • Abacate
  • Frango
  • Manga
  • Feijão

Lista ordenada (ol)

uma lista ordenada é usada quando os itens possuem uma sequencia, uma classificação, ou uma ordem que precisa ser respeitada

  1. Acordar
  2. Escovar os dentes
  3. Tomar café
  4. Estudar
  5. Almoçar
  6. Jogar warzone

Lista de descrição (dl)

Usamos uma lista de descrição quando precisamos descrever algum termo.

Para criarmos essa lista, utilizamos 3 elementos

  1. dl (description list): Representa a lista de descrição
  2. dt (description term): Representa o termo /li>
  3. dd (data descrição): Representa a descrição do termo
