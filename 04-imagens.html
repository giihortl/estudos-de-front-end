      Sobre os diferentes tipos de imagens

      Abaixo, temos uma lista dos diferentes tipos de imagens e quando usar:

      • JPEG/JPG : Bom para fotos de produtos, paisagens e fotos, pois, possui muitas cores e possui um arquivo relativamente pequeno.
        Não suporta tranparencia e caso seja comprimida várias vezes, pode perder qualidade.
      • PNG : Excelente escolha quando queremos transparencia e preservar bastante a qualidade.
        Geralmente usamos para logos, imagens com tranparencia, graficos simples, etc.
      • WebP : Formato moderno desenvolvido para web.
        Muito menor que JPEG E PNG, mantém a qualidade da imagem pois suporta compressão sem perda. Usamos para qualquer imagem comum na web.
      • AVIF : Assim como o formato WEBP, é um formato moderno e também é capaz de produzir arquivos bastante pequenos mantendo uma ótima qualidade.
        Geralmente usamos esse formato quando queremos priorizar performance.
      • SVG : O SVG é um elemento vetorial, excelente para logos, icones, ilustrações, formas geometricas e graficos.
        A vantagem desse elemento é que ele pode ser ampliado sem a mesma perda de nitidez de uma imagem baseada em PIXELS.
