Formulários HTML

O que são formulários no HTML?

Os formulários são uma das partes mais importantes do HTML pois ajudam a introduzir uma ideia diferente.

O usuário deixa de apenas consumir conteúdo e passa a fornecer dados para o sistema.

Um formulário de forma resumida, é uma área da página destinada a coleta de informações.

Exemplos de uso:

  • Login
  • Cadastro
  • Contato
  • Pesquisa
  • Comentários
  • Endereço
  • Inscrições em Newsletter

Criando um formulario basico

exemplo de formulario de entrar em contato:

  • <label > : representa um rotulo/etiqueta para um campo. É um recurso fundamental para a acessibilidade
  • For : para conectarmos o nosso rotulo (label) ao input, utilizamos o atributo FOR. ele serve para criar a relação com o id do input
  • Id : esse atributo serve para identificar de forma unica um elemento dentro da pagina.
  • type : Esse atributo serve para definirmos o tipo de input que desejamos apresentar para o usuario com base no dado que queremos coletar.
